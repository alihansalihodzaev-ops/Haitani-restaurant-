# Deploy checklist

- [ ] Push project to GitHub.
- [ ] Import repository in Vercel (Next.js preset).
- [ ] Add `OPENAI_API_KEY` as a server environment variable (optional for demo mode).
- [ ] Add `OPENAI_MODEL` if a non-default model is selected.
- [ ] Deploy and test `/api/ai/compose`.
- [ ] Confirm the generated `*.vercel.app` domain.
- [ ] Replace demo prices and images before public restaurant use.
- [ ] Add Supabase and server-side order processing before accepting real orders.
