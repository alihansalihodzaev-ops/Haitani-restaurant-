# HAITANI — Premium Japanese Digital Menu

Адаптивный стартовый проект цифрового меню HAITANI на Next.js 14, React, TypeScript, Tailwind CSS и Framer Motion. Включает каталог с поиском/фильтрами/сортировкой, конструктор суши, серверный AI endpoint с безопасным демо-режимом и корзину с сохранением в localStorage.

## 1. Запуск локально

Требуется Node.js 20 LTS или новее и npm.

```bash
npm install
cp .env.example .env.local
npm run dev
```

Откройте http://localhost:3000.

## 2. Подключение OpenAI

1. Создайте API key в кабинете OpenAI.
2. Откройте `.env.local` и укажите `OPENAI_API_KEY=ваш_секретный_ключ`.
3. При необходимости задайте `OPENAI_MODEL=gpt-4o-mini`.
4. Перезапустите dev-сервер.

Ключ используется только в `app/api/ai/compose/route.ts` на сервере. Не добавляйте префикс `NEXT_PUBLIC_`, не вставляйте ключ в React-компоненты и не коммитьте `.env.local`. Без ключа endpoint работает в demo-режиме: простые запросы сопоставляются с локальным каталогом. Демо не является настоящей генеративной моделью.

## 3. Публикация на Vercel

1. Создайте GitHub-репозиторий и загрузите в него содержимое папки `haitani`.
2. Войдите на https://vercel.com и выберите **Add New → Project**.
3. Импортируйте репозиторий. Framework Preset: Next.js; Build Command: `npm run build`.
4. В Project Settings → Environment Variables добавьте `OPENAI_API_KEY` и `OPENAI_MODEL` (если используете настоящий AI).
5. Нажмите Deploy. Vercel выдаст бесплатный адрес вида `project-name.vercel.app`. Имя `haitani.vercel.app` будет доступно, только если оно свободно.

## 4. Где менять меню и цены

- `lib/menu.ts` — категории, блюда, фотографии, ингредиенты и цены.
- `components/MenuSite.tsx` — интерфейс, каталог, конструктор и корзина.
- `app/api/ai/compose/route.ts` — серверная логика AI, проверка структуры и demo fallback.
- `app/globals.css` — тема, адаптивность и стили.

Цены в `lib/menu.ts` и `ingredients` — демонстрационные, перед запуском ресторана замените их на утверждённый прайс. Фото — внешние изображения Unsplash; перед коммерческим запуском проверьте лицензии и замените их на собственную фотосъёмку блюд.

## 5. Архитектура и следующие этапы

Сейчас это front-end MVP: корзина сохраняется в браузере, оформление заказа демонстрационное, Supabase не подключён. Для production следует добавить Supabase таблицы `menu_items`, `orders`, `order_items`, `custom_recipes`, авторизацию админ-панели, серверное создание заказов, оплату, валидацию аллергенов персоналом, rate limiting и мониторинг. AI получает только разрешённый каталог и возвращает структурированный рецепт; стоимость всегда рассчитывает клиент из локального прайса, а сервер валидирует имена продуктов.

## Проверка

```bash
npm run build
```

Проверяйте AI как с ключом, так и без него; корзину после перезагрузки; пустые поисковые результаты; разные количества ингредиентов; мобильные ширины 360–430 px.
